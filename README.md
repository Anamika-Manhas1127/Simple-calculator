# Calculator App

This is a simple web-based calculator application that performs basic mathematical operations such as addition, subtraction, multiplication, and division. The calculator features a clean user interface and includes a reset button to clear the input fields.

## Project Structure

```
calculator-app
├── index.html        # Main HTML document for the calculator UI
├── css
│   └── styles.css    # Styles for the calculator's user interface
├── js
│   └── script.js     # JavaScript code for calculator functionality
└── README.md         # Documentation for the project
```

## Features

- Addition, subtraction, multiplication, and division operations
- Clear and user-friendly interface
- Reset button to clear inputs

## Instructions for Use

1. Open `index.html` in a web browser.
2. Enter numbers in the input fields.
3. Click on the desired operation button to perform the calculation.
4. View the result displayed on the screen.
5. Use the reset button to clear all inputs and results.

## Additional Notes

- This project is built using HTML, CSS, and JavaScript.
- Ensure that JavaScript is enabled in your browser for the calculator to function properly.
